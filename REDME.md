# Fitness Data Analysis

Python script for data cleaning, anomaly detection, and visualization of daily fitness metrics.

## Key Features
- **Data Integrity Checks:** Identifies null values, duplicates, and out-of-range records (e.g., negative ages, unrealistic exercise/water metrics).
- **Data Visualization:** Employs Seaborn boxplots to spot distribution outliers across features.

## Files in Repository
- `Copy_of_Fitness_066.ipynb`: Jupyter Notebook with complete analysis code.
- `06_fitness_data.csv`: Source dataset.
